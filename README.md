# Teachable Machine Coloring 🎨

An interactive experiment that uses **Teachable Machine**, **TensorFlow.js**, and **p5.js** to detect colors via webcam and apply them to SVG images.  
Show a color to your webcam → then click on an image → watch it change color dynamically.

---

## Demo

**How it works:**
1. Hold a color in front of your webcam.  
2. The app detects the color (`Detecting color...` label updates).  
3. Click an SVG image (fish, bubbles, etc.) → it fills with the detected color.
